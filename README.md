# Raine's Terminal File Manager (RTFM)

This is a public domain TUI-based file manager made by yours truly. Use W/S to go up and down the sidebar and arrow keys to scroll up and down. Also, use PgUp and PgDown to scroll faster. Use the spacebar to navigate through directories. The double dot puts you in the folder containing your current directory. Made for Linux, but should work with other Unix systems. Might want to port to Windows later.
